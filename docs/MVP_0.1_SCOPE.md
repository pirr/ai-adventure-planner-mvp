# MVP 0.1 Scope Notes

MVP 0.1 focuses on proving the main product hypothesis:

> A user can receive a useful nearby adventure recommendation faster than by manually searching Google Maps, reviews, weather and route data.

## Included now

- Location input
- Time input
- Transport input
- Group and children context
- Interests
- Weather awareness
- Route-time estimation
- Adventure Score
- Recommendation explanations
- Warnings
- Rejected alternatives
- Open in Maps
- Feedback capture

## Deferred

- User accounts
- Adventure Memory
- Photo diary
- Long-term personalization
- Community Intelligence
- Event Impact Layer
- Live traffic data
- Real road closure feeds

## Reason

The most important validation question is not whether the app can eventually know everything. The first validation question is whether users trust and like the recommendation format.
